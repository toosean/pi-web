# 本地升级与优化清单

## 统计口径

对比范围为共同祖先 `v0.8.11` 到当前提交 `3d66f3d`。本地共有 37 个功能或修复提交，另有 3 个上游同步合并；净改动约 125 个文件、`+11,455 / -3,417`。

以下按最终形成的能力归并，连续演进的提交不重复计算。

## 1. 会话切换与性能

- 会话窗口常驻，切换会话不再卸载 `ChatWindow`，保留消息、草稿、滚动位置和流式状态。
- 后台运行的会话继续接收事件；空闲窗口释放 SSE，限制并发流数量，避免 HTTP/1.1 连接耗尽。
- 桌面端最多保留 8 个窗口、移动端 4 个；忙碌窗口和含草稿窗口不会被误回收。
- 客户端会话正文缓存，切回近期会话可直接渲染并后台校验。
- 服务端按文件身份缓存会话正文；实测读取从约 `2.2s` 降至 `12-39ms`。
- 会话目录改为增量元数据扫描；824 个会话热扫描从约 `4867ms` 降至 `20ms`。
- 模型配置、主目录、最近项目和 worktree 列表增加 `localStorage + SWR` 缓存，加快新建会话首屏。
- 会话分页按完整用户轮次对齐，避免历史加载截断半轮对话。
- 草稿存储增加 LRU 上限，防止附件 Base64 长期占用内存。

相关提交：`a360592`、`90a63ce`、`2a0f3ad`、`0352911`、`925aecf`

## 2. 会话管理与侧边栏

- 新增 Flat 会话视图。
- 新建会话时可直接选择项目和分支。
- Flat 视图显示项目名，并默认聚焦最近 24 小时的活跃会话。
- 支持滑动隐藏会话、恢复隐藏会话和按需显示更早记录。
- 支持会话置顶、隐藏、未读状态。
- 置顶、隐藏、未读最终升级为服务端持久化，跨设备、清理浏览器数据后仍保留，多标签页可同步。
- 自动迁移旧 `localStorage` 标记到 `~/.pi-web/session-preferences.json`。
- Session 操作收进更多菜单，并支持复制会话文件路径。
- 新会话创建期间增加 pending 行，减少列表状态跳变。

相关提交：`0a4b03f`、`22ffe64`、`07eae80`、`70c30a0`、`09ebb8b`、`925aecf`、`3d66f3d`

## 3. 聊天输入与交互

- 输入框支持 `$` 技能搜索、模糊匹配和自动补全。
- 支持上传并附加通用文件，不再局限于图片。
- 首轮对话结束后可由服务端配置自动生成会话标题。
- 工具调用参数支持 YAML 显示，多行 Shell 命令以块文本展示。
- YAML/JSON 由运行时变量 `PI_WEB_TOOL_INPUT_FORMAT` 控制，无需重新构建。
- 每一条 assistant 阶段消息显示自己的完成时间，而不只显示整轮最后时间。
- Markdown 中的 localhost/127.0.0.1 链接可替换为外部可访问的 BASE URL。
- 内联代码中的本地 URL 可直接点击。

相关提交：`80176a7`、`8960a5f`、`aa3a22f`、`938bd7d`、`7a8bc1e`、`98bc5fd`

## 4. 文件与工具结果展示

- 每轮回复增加 `Files modified` 修改文件汇总。
- 修改文件使用本地折叠卡片展示，并接入上游文件提取逻辑。
- `read` 工具读取图片时显示缩略图，点击可进入文件预览。
- 图片附件增加压缩规则，小于 `800x800` 时保留原图。
- 文件预览支持应用内 Panel 级全屏。
- 优化目录树展开时的加载 Spinner。
- 文件访问授权增强，支持相对路径和内存中尚未落盘的会话引用。
- 增加 `PI_WEB_ALLOW_ALL_FILES` 运维开关。该开关会绕过文件访问限制，合并时需要特别保留其安全提示。

相关提交：`75f3d3a`、`92963e0`、`75b12b7`、`4a3bf3a`、`696dcec`、`5f21030`

## 5. PWA、移动端与客户端

- 支持 Web Push 完成通知。
- 安装后的 PWA 图标显示运行中会话数量角标。
- 增加 PWA 安装提示和 iOS 添加到主屏幕引导。
- 开发环境自动注销旧 Service Worker，避免缓存干扰调试。
- 静态资源采用 Cache First / Stale While Revalidate，改善二次打开速度。
- 支持移动浏览器及 WebView 的返回手势、浏览器历史导航和面板返回逻辑。
- 仓库内提供 `xiaomi-ubuntu-pi.apk` Android 客户端安装包。

相关提交：`3c77116`、`93caaa4`、`0e655d8`、`8bfc7af`、`9d4b9b4`

## 6. Extension 展示

- 新增 `GitFooterWidget`，展示 `git-footer-status` 扩展输出。
- 支持多行、自适应宽度和响应式换行。
- Extension 底部状态栏增加溢出检测、折叠和展开。
- 后续修复上游同步后状态栏折叠能力丢失的问题。

相关提交：`af96038`、`03f492e`、`58916c3`

## 7. 部署与运维

- 新增 PM2 `ecosystem.config.cjs`。
- 支持 `PI_WEB_DIST_DIR`，可在独立目录构建生产版本，再原子替换线上 `.next`。
- PM2 环境显式保存工具显示格式、Allowed Hosts、文件访问等配置。
- PM2 重启改用 `SIGKILL`，避免 SSE 长连接阻塞退出并造成 `EADDRINUSE` 重启循环。
- HTTPS 反向代理场景下，Origin 校验支持 `X-Forwarded-Proto`。

相关提交：`58b88ea`、`5dbde9c`、`777f9d7`、`2b29b4d`、`925aecf`

## 8. 稳定性修复

- 修复切换会话时重复重置 cwd、触发不必要重载的问题。
- 修复隐藏的后台窗口覆盖前台窗口，吞掉点击和滚轮事件的问题。
- 修复复用同 cwd 草稿窗口时激活不存在的 window id，导致全部聊天窗口被卸载的问题。
- 前台窗口独占顶栏状态和 Esc 操作，防止后台窗口覆盖当前 UI。
- 完成通知和提示音按实际完成的窗口触发，避免归属到错误会话。

相关提交：`90a63ce`、`925aecf`、`700b763`、`2e79a4d`

## 合并前重点

合并时最需要防止回退的是以下四组本地核心能力：

1. 服务端会话标记。
2. 常驻会话窗口与缓存。
3. PWA 与移动端能力。
4. YAML 工具参数与文件增强。

会话保活、元数据缓存和流式恢复与新版上游已有独立实现，应先做能力对照再融合，不能简单选择任意一侧代码。
